Advanced Web Course Architecture — How OmniInspect Works

            
100% Free Client-Side HTML, CSS & JavaScript Inspection Pipeline

          

        

        
      


      

        

          
1. Multi-Engine Free CORS Waterfall

          
Browsers block direct cross-origin fetch() calls due to Same-Origin Policy. This tool implements an automatic failover waterfall across 4 free public CORS engines (AllOrigins, CodeTabs, CorsProxy.io, and direct fetch) plus offline HTML source parsing.

        

        

          
2. Native Browser DOMParser AST

          
Instead of fragile regex-only HTML parsing, the fetched string is fed into new DOMParser().parseFromString(html, 'text/html'). This builds an inert in-memory DOM tree without executing untrusted third-party scripts (preventing XSS).

        

        

          
3. Wappalyzer-Style Tech Fingerprinting

          
Our signature engine inspects <script src>, <link href>, <meta name="generator">, custom DOM attributes (data-reactroot, ng-version, hx-get), and CSS class patterns to identify 45+ frameworks and tools.

        

        

          
4. Typography, SVG & Media Extraction

          
Parses Google Fonts / Bunny Fonts URL parameters, @font-face rules, and CSS font-family stacks, while resolving relative <img src> paths via the new URL(relative, baseUrl) Web API.
