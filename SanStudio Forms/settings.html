Setup Instructions

  1. Open Google Apps Script and create a new project.
  2. Create a Google Sheet and link it to your script, or use the active spreadsheet.
  3. Copy the contents of backend/Code.gs into your Apps Script editor.
  4. Run the setup() function once to initialize the spreadsheet.
  5. Deploy as Web App: Execute as Me, Access Anyone.
  6. Copy the deployment URL and paste it above.
